### New

- Diagnostics search every wired link of the head unit for the car's gateway, the car's internal network on G-series cars included: they ask who the gateway is, try the addresses where it is usually found and another tester address when the gateway refuses the usual one.
- The gateway found is remembered, so the next start of an application reads engine data at once.

### Improved

- The diagnostics connection stays open between an application's requests instead of being made again for each one.

### Good to know

- The new search has not run in a car yet. With Debug log on, open Gauges for a minute and share the Manager log: it says what the head unit's links hold and what each address did.
- Some cars reach the gateway through the head unit's link only while something is plugged into the OBD port. If the internal network does not answer either, Gauges keeps showing iDrive's car data.
