### New

- Diagnostics also speak DoIP, the newer diagnostic protocol some gateways use, and look for a DoIP gateway on every wired link of the head unit.
- A device on the car's network that does not answer as the gateway but passes requests to the engine computer is used for engine data.

### Improved

- When the manager's screen cannot be drawn, the Manager log says what failed.

### Good to know

- Not yet tried in a car. With Debug log on, open Gauges for a minute and share the Manager log: its `diag:` lines say what each device on the car's network did.
