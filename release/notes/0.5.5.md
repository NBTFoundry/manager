### New

- Touch on the manager's own screen: tap a row, drag to move through a list, swipe right for BACK. iDrive keeps its touches whenever it is shown. Applications do not take touches yet.
- Diagnostics look for the car's gateway. When the usual address does not answer, the manager tries the addresses the head unit already talks to on the car's Ethernet link and keeps the one that answers. With Debug log on, the Manager log says what it found there and what each address did.
- Car data reaches applications built as modules and guests.

### Fixed

- Self test: diagnostics and the phone page are checked by the native program, the only form that can do them; the sound check passes when queues only grew.
